# macOS 27 （Mac mini M4Pro）系统可用软件合集

### 1、调整外接第三方显示器（PA279CRV）亮度&平滑度

>由于外接显示器，亮度调整以及显示器音量调整都无法使用Magic键盘快捷键进行调整，同时外接显示器分辨率调整到3840以下后出现的文字虚边。未解决上述问题，找到了Crisp (https://github.com/didriksg/Crisp)
>该应用可以完美解决上述全部问题，比起MonitorControl“无法调整平滑度”，以及Better Disaplay"无法锁定显示器亮度，导致引用重启或电脑重启亮度就恢复到15%，显示器会很暗"。Crisp既可以完成显示亮度快捷调整，显示扬声器音量也可以。
